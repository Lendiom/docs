title: What is a 10DLC Campaign?
---

A 10DLC (10 digit long code, aka regular phone number) campaign is the definition of how you will be using the phone number(s) that are attached to the brand and campaign.

Lendiom pre-populates the required information based on the stereotypical businesses which use Lendiom. If you are using it in a non-standard way, please contact us so we can help guide you through the process.
